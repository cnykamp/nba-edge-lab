# Version history

## 0.1.0 — 2026-10-24

- Established the private repository and agreed product scope.
- Added a responsive local dashboard with explicit unconnected/untrained states.
- Added browser-local manual bet entry, user-reported settlement, realized/one-unit accounting, and JSON export.
- Documented free-data feasibility, unverified bet365 MI coverage, and missing historical-price evidence.
- Defined point-in-time evaluation and model-promotion requirements before model development.
- No live integration, trained model, automated job, probability interval, verified market edge, hosting, or device synchronization is included.
